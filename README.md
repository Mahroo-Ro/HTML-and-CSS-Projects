# HTML and CSS Projects

Welcome to my repository showcasing all the projects completed during the HTML and CSS Course.

---

## 📁 Projects Included

### 1. [Portfolio Website](./Portfolio-Website)
* My personal portfolio website built with clean, responsive HTML5 and modern CSS3 (Flexbox & CSS Grid). Showcases all featured course works and includes an interactive contact form layout.

### 2. [Academy Cinemas](./Academy-Cinemas)
* A responsive multi-page cinema website built with **Bootstrap 4** and customized CSS, featuring movie listings, showtimes, card layouts, and a ticket registration modal.

### 3. [One-Page Website](./One-Page-Website)
* A modern single-page website layout built from scratch with smooth scrolling, navigation bars, and embedded media components.

### 4. [Simple Recipes](./Simple-Recipes)
* A structured food recipe page emphasizing semantic HTML tags, custom typography, tables, and structured lists.

### 5. [The Pet Shop Website](./The-Pet-Shop-Website)
* An e-commerce landing page interface built for a pet store, demonstrating card containers, structured grids, and clean layout design.

### 6. [Creating CSS Effects](./Creating-CSS-Effects)
* A collection of modern CSS techniques, including hover effects, transitions, transform properties, and keyframe animations.

## 🛠️ Technologies Used
* **HTML5** (Semantic elements, responsive layout structures)
* **CSS3** (Flexbox, CSS Grid, custom animations, media queries)
* **Bootstrap 4** (Responsive grid systems, modern components)
* **Git & GitHub** (Version control and GitHub Pages deployment)
